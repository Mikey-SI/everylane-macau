# 街知巷聞 · 決賽 10 分鐘路演講稿

隊伍：愛拼才會贏　｜　主講：施天益　｜　目標時長：9 分 30 秒（預留 30 秒）

> 核心句只記一條：**我們不是再做一個旅遊聊天機械人，而是用 AI 把人流帶入舊區，再用到店碼證明價值。**

## 0:00–0:40｜封面：一句話打中問題

各位評審好，我是施天益。澳門不缺景點，也不缺旅遊攻略；澳門真正缺少的，是一個能把遊客從過度集中的熱門點，帶到有文化、有小店、但缺客流的舊區，而且能證明這次導流有沒有產生價值的系統。

所以我做了「街知巷聞」：一個基於 Qwen、QwenPaw、Skill 與 MCP 的澳門深度遊 AI Agent。

## 0:40–1:25｜問題：不是資訊不足，而是流量分配失衡

左邊是大三巴、議事亭和路氹：擠迫、排隊、體驗同質化。右邊是福隆新街、內港和下環：有文化、有故事、有本地商戶，但客流和數碼能力較弱。

一般推薦系統按熱門度排序，只會令熱門更熱門。「街知巷聞」反過來，把旅遊規劃變成一個受限制的流量分配任務：既滿足遊客興趣、日期、預算與步行偏好，又主動避峰、導流，最後量度到訪。

## 1:25–2:15｜產品：一句自然語言，完成整個任務

使用者只需說一句，例如：「星期三想帶父母看歷史、吃地道美食，而且少走路。」

阿濠會理解需求，查天氣、搜索景點、逐站核對開放時間、預測人流、找附近舊區替代點、計算步行路線與預算。結果不是一段聊天文字，而是地圖、時間軸、每站理由、無障礙資訊、限制條件核對，以及可領取的一次性到店碼。

## 2:15–3:10｜技術：模型決策、工具求證、安全層把關

這個作品的技術重點不是把 Prompt 寫長，而是分清三種責任：

1. Qwen / QwenPaw 負責理解與 ReAct 決策；
2. EveryLane MCP 的 7 項工具負責天氣、開放、人流、路線與預算等事實；
3. 確定性安全核對器負責最後把關。同區、當日開放、少步行、預算等條件未通過，就不能 submit。

因此模型可以有創意，但不能杜撰關鍵事實。

## 3:10–3:55｜智能體能力：現場演示失敗恢復

現在按首頁的「90 秒評審快速演示」。

演示問題指名「星期三去鄭家大屋」。工具 `check_opening` 會發現鄭家大屋逢星期三休息。一般聊天機械人可能仍把它排進行程；阿濠會在同區找有開放的替代點，重新計算人流、路線與預算，全部核對後才提交。

請評審留意左側 SSE 軌跡：這是「規劃 → 工具 → 觀察 → 修正 → 提交」，而不是預先寫好的答案。

## 3:55–4:50｜產品亮點：從推薦到可歸因閉環

行程中的本地商戶可領取 `EL-XXXX-XX` 一次性到店碼。切到成效儀表板，把代碼貼進核銷機：

- 第一次核銷成功；
- 第二次立即被拒；
- 代碼不含身份資料。

這把「推薦了某間店」變成「可以量度是否到店」，也是商戶按效果付費的結算基礎。

## 4:50–5:45｜成效：達到計劃書指標，也把真實性講清楚

複賽規則容許非真實數據，但要求呈現效果達到計劃書指標。我的處理方式不是把數據包裝成真的，而是分成兩欄：

- 真實即時：Qwen / 工具鏈、Open-Meteo、到店碼、B 端 API、70 個 POI、無障礙資料與自動化測試；
- 示範數據：可用性、累計轉化、區域熱度與模型校正。

示範指標包括導流覆蓋率 86.4%、路線可行率 98.9%、商戶到訪率 41.8%。頁面明確標註，公式、生成種子、來源檔和核驗端點可由 `/api/impact/evidence` 下載。

## 5:45–6:35｜商業模式：三個付費方、同一套核心能力

第一，商戶精選訂閱或按核銷效果付費；第二，酒店與旅行社使用白標行程 API；第三，文旅部門訂閱匿名化區域熱度儀表板。

它的護城河不是景點清單，而是三層結合：澳門舊區資料層、以承載平衡為目標的決策層，以及「推薦—到訪—核銷—歸因」閉環。

## 6:35–7:30｜可靠性：路演不能靠模型當天運氣

真實 Qwen 服務在線，但供應商偶爾可能受限。因此我沒有把風險藏起來：

- 單次模型請求 45 秒逾時；
- 整體 Qwen 時間預算 110 秒；
- 逾時後由同一知識庫與工具鏈接管；
- 軌跡與結果徽章明確顯示實際引擎，不把回退冒充 Qwen；
- GitHub Pages 提供靜態備援。

目前後端 641、瀏覽器 119、API / 安全 101、MCP 8 工具協議測試全部通過。

## 7:30–8:15｜AI 倫理與限制

我主動保留四項限制：

1. 人流是模型估算，不是官方即時客流；
2. 步行是坐標與巷道係數估算，不是逐路口導航；
3. 複賽商戶與可用性累計是示範數據，正式試點需要商戶書面同意；
4. 到店碼是可操作原型，商用還要加入商戶帳戶、權限、限流與審計。

透明、可撤回、最小化收集，是這個產品商用前不會妥協的底線。

## 8:15–9:00｜為何值得第一名

這個作品同時對準官方三個核心關注：

- 創意：不是熱門推薦，而是舊區導流；
- 技術：真實 Qwen / QwenPaw、MCP、多步工具與失敗恢復；
- 價值：到店碼與 B 端 API 把社會價值變成可量度商業價值。

更重要的是，計劃書中晉級後承諾的即時天氣、無障礙、商戶試點、模型校正與儀表板，全部已經變成評審可以親手操作的功能。

## 9:00–9:30｜收結

我們完成的，不是一份漂亮行程；而是一個能把旅遊流量帶入舊區，再用到店碼證明價值的 AI Agent。

街知巷聞不只推薦澳門，它重新分配澳門的旅遊流量。多謝各位評審，歡迎提問。
