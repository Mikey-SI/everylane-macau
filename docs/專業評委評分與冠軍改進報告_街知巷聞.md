## 三、為什麼還不是「穩拿第一」

同級隊伍只要具備下面任一項，仍可能反超：

1. **真實商戶試點核銷**（哪怕一間店、十張碼）  
2. **HTTPS 域名**（現在是 HTTP IP）  
3. **現場 Qwen 從不空等**，且多日也走模型迴圈  
4. **路演 10 分鐘**把「導流 → 領碼 → PIN 核銷 → 儀表板分母」講成一個故事

94 分的意思是：在複賽允許示範數據的前提下，產品完成度與智能體證據已在決賽第一梯隊；冠軍取決於公網與現場。
