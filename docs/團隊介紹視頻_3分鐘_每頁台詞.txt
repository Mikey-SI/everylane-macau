============================================================
第 1 頁｜開場定位（0:00–0:12）
============================================================
大家好，我是「愛拼才會贏」隊長施天益。我的作品叫「街知巷聞」，
是一個把遊客從擁擠熱點，智能導流到澳門老街和本地小店的
QwenPaw 旅遊智能體。

============================================================
第 2 頁｜團隊成員介紹（0:12–0:34）
============================================================
我目前是澳門大學計算機相關專業學生，具備 AI、全端開發、資料工程
和 Web 安全實作經驗，也有 AIA 實習及 CTF 競賽經歷。這次由我一人
完成產品構思、景點資料、QwenPaw Skill、MCP 工具、前後端和測試。

============================================================
第 3 頁｜為什麼開發（0:34–0:55）
============================================================
我做這個項目，是因為澳門旅遊有一個明顯矛盾：大三巴和議事亭長期
擁擠，但幾分鐘路程以外的老街和街坊小店，未必得到同樣客流。
我希望 AI 不只回答問題，而能真正重新分配旅遊流量。

============================================================
第 4 頁｜QwenPaw 實際部署（0:55–1:23）
============================================================
我已在本地部署 QwenPaw 2.0.0，建立「阿濠」專用 Skill，並用 MCP
接入七個細粒度工具和一個完整流程工具。它會查天氣、搜尋七十個真實
澳門景點、逐站核實開放時間、預測人流、尋找附近老街，再計算路線和
預算。每一步都有工具結果可以核對，不是模型憑空生成。

============================================================
第 5 頁｜失敗恢復場景（1:23–1:51）
============================================================
例如用戶星期三指定鄭家大屋，阿濠會用 check_opening 發現當日休息，
不會硬排入行程，而是自動改為同區有開放的歷史點。遇到大三巴正午
人多，它會把熱門點錯峰，再導流到草堆街等附近老街。這就是規劃、
工具調用、多步執行和失敗恢復，而不只是問答。

============================================================
第 6 頁｜可驗證產品輸出（1:51–2:13）
============================================================
最後輸出不是一段空泛文字，而是地圖、時間軸、人流、開放時間、
估算步行距離、預算和任務完成核對。網站支援一至五日分區行程，
也支援繁中、簡中、英文、葡文和日文，並可把 AI 行程單獨存成 PDF。

============================================================
第 7 頁｜商業與社會價值（2:13–2:34）
============================================================
對遊客，它減少排隊和查資料的時間；對小店，它創造可量化的新客流；
對城市，它協助平衡旅遊承載。下一步會以到店碼驗證導流轉化，再向
酒店、旅行社和文旅管理者提供行程 API 與匿名化熱度分析。

============================================================
第 8 頁｜完成度與結尾（2:34–2:52）
============================================================
目前項目已完成六輪回歸及公網實測：後端六百四十一項、瀏覽器九十九項、
API 與安全六十四項全部通過；七十個景點都有圖片，八個 MCP 工具通過
協議測試。歡迎體驗畫面上的連結。我希望「街知巷聞」令遊客看見
大三巴以外的澳門，也令每一條老街重新被看見。謝謝。
