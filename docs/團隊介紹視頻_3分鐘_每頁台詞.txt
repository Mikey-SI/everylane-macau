============================================================
大家好，我是「愛拼才會贏」隊長施天益。我的作品叫「街知巷聞」。
它不是又一個只會推薦大三巴的聊天機械人，而是一個會把遊客從擁擠熱點，
智能導流到澳門老街和本地小店的 QwenPaw 旅遊智能體。
線上演示連結已打在畫面：http://47.79.228.128/

============================================================
第 2 頁｜為什麼做（約 0:15–0:40）
畫面：「同一座城市，兩種完全不同的人流」+ 地圖
============================================================
我目前是一人團隊，由我負責產品構思、景點資料、智能體工具、網站和測試。
我做這個項目，是因為澳門旅遊有一個很明顯的矛盾：大三巴和議事亭長期
擁擠，但幾分鐘路程以外的老街和街坊小店，卻未必得到同樣客流。
我希望 AI 不只是回答問題，而是真正重新分配旅遊流量。

============================================================
第 3 頁｜QwenPaw 實際部署（約 0:40–1:20）
畫面：QwenPaw MCP / Skill（勿露出 API Key）
============================================================
我已在本地部署 QwenPaw 2.0.0，建立「阿濠」專用 Skill，並用 MCP
接入八項能力。它會先查天氣、搜尋七十個真實澳門景點，再逐一核實開放
時間、預測人流、尋找附近老街、計算步行路線和預算。
這些不是模型憑空生成的文字，而是每一步都有工具結果可以核對。

============================================================
第 4 頁｜失敗恢復場景（約 1:20–1:55）
畫面：鄭家大屋星期三 → 自動改線
============================================================
例如用戶星期三指定鄭家大屋，阿濠會用工具發現它當日休息，不會硬排入
行程，而是自動改為同區有開放的歷史點。遇到大三巴正午人多，它會把
熱門點錯峰，再導流到草堆街等附近老街。最後才計算路線和預算。
這就是規劃、工具調用、多步執行和失敗恢復，而不只是問答。

============================================================
第 5 頁｜可驗證的產品輸出（約 1:55–2:15）
畫面：地圖 + 時間軸行程結果
============================================================
每個結論都有數據可以核對：地圖、時間軸、人流、開放時間、步行距離、
預算，還有任務完成核對。網站支援一至五日分區行程，也支援繁中、簡中、
英文、葡文和日文。PDF 只輸出 AI 行程結果，方便評審與遊客帶走。

============================================================
第 6 頁｜商業與社會價值（約 2:15–2:35）
畫面：三方共贏 + Skill 啟用截圖
