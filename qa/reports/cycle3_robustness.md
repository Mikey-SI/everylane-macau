# 生命周期 3 报告 — 健壮性、安全与边界输入

日期：2026-07-11  
测试：`qa/test_api.py` + `qa/test_backend.py`

## 批判性检查与修复

1. **真实 Qwen 可能提前提交**：原逻辑信任模型遵循 Prompt，模型理论上可未查完
   工具就 `submit_itinerary`。现记录已调用工具与已核实 POI；缺少天气、搜索、
   开放、人流、路线、预算任一工具，或有站点未 `check_opening`，均拒绝提交并
   要求继续验证。
2. **真实 Qwen 可能提交休息／跨岛／重复点**：新增确定性安全层
   `_sanitize_qwen_ids`，过滤不存在、重复、当日休息与跨片区站点，并再次执行
   低步行和预算约束；不足 3 站自动回退稳定规划器。
3. **最终组装器只过滤无效 id，未真的过滤休息点**：`assemble` 现二次过滤并在
   notes 记录移除原因。
4. **API 可接受任意大查询与任意语言码**：限制需求 1000 字、日期字段 32 字，
   语言仅允许五种；前端 textarea 同步 maxlength。
5. **静态文件路径检查使用字符串前缀**：改用 `os.path.commonpath`，防止目录穿越。
6. **异常会把 Python 类名／内部错误显示给用户**：服务端完整记录日志，SSE 只返回
   不泄露内部细节的友善错误。
7. **缺少浏览器安全头**：加入 CSP、nosniff、DENY frame、referrer 与
   camera/microphone/geolocation 权限策略。
8. **输入框无可访问名称**：加入五语言 `aria-label`。
