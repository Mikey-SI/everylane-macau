B 端變現 · 酒店與旅行社 API

計劃書商業價值路徑：商戶精選訂閱／引流分成 · 酒店與旅行社 API · 文旅數據儀表板。

POST /api/v1/itinerary

一個請求返回完整可驗證行程（站點、時間軸、路線、預算、舊區歸因），供酒店禮賓部／旅行社系統直接嵌入。

curl -X POST http://47.79.228.128/api/v1/itinerary \
  -H "Content-Type: application/json" \
  -H "X-API-Key: el-demo-2026" \
  -d '{"query": "帶爸媽玩一日，歷史美食，唔想行太遠", "lang": "zh-HK"}'

演示金鑰 el-demo-2026 · 完整說明見 API 文檔。

三條變現路徑的儀表板對應

  • 商戶精選訂閱／引流分成 — 上方到店碼核銷數據即按效果計費的結算依據。
  • 酒店與旅行社 API — 左側 v1 API 已可調用，返回含舊區歸因的行程 JSON。
  • 文旅數據儀表板 — 本頁匿名化區域熱度即政府／業界訂閱版的雛形。
