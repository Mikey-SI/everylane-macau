B 端 API · v1

計劃書商業價值路徑 · 酒店與旅行社 API

一個請求，返回可驗證的澳門深度遊行程

與網站共用同一套知識庫（70 POI）與 7 項工具；返回含地圖坐標、時間軸、預算、無障礙與舊區歸因的 JSON，可直接嵌入酒店禮賓部、旅行社與 OTA 系統。

演示環境開放金鑰 el-demo-2026（放在 X-API-Key 請求頭）。正式合作將簽發獨立金鑰並按調用量／效果計費。

1. 行程規劃 API

POST /api/v1/itinerary

請求體（JSON）：query 自然語言需求（≤1000 字）· lang 可選 zh-HK / zh / en / pt / ja · today 可選 YYYY-MM-DD。

curl -X POST http://47.79.228.128/api/v1/itinerary \
  -H "Content-Type: application/json" \
  -H "X-API-Key: el-demo-2026" \
  -d '{"query": "帶爸媽玩一日，歷史美食，唔想行太遠", "lang": "zh-HK"}'

返回示例（節錄）：

{
  "api_version": "v1",
  "engine": "deterministic-tools",
  "attribution": {
    "old_district_stops": 4,
    "local_business_stops": 4,
    "est_local_spend_mop": 135
  },
  "itinerary": {
    "title": "你的澳門深度漫遊",
    "date": "2026-08-26", "weekday": "週三",
    "weather": { "condition": "雷陣雨", "temp_c": 30, "source": "open-meteo-live" },
    "totals": { "stops": 6, "walk_km": 2.1, "cost_mop": 270, "old_district": 4, "local_business": 4 },
    "constraints": [ { "label": "全部景點當日開放", "ok": true } ],
    "stops": [ { "name": {"zh": "福隆新街"}, "arrive": "10:00",
                 "accessibility": {"step_free": true}, "crowd": {"label": "適中"} } ]
  }
}

無效或缺失金鑰返回 401；規劃引擎為確定性工具鏈（低延遲、可重現），與網站的實時 Qwen 推理共用同一知識庫與核驗規則。

2. 成效數據 API（匿名化 · 唯讀）

端點內容
GET /api/impact/summary計劃書指標對照、可用性測試、轉化漏斗、人流模型校正摘要
GET /api/impact/heat匿名化區域熱度（6 區、21 日走勢）與模型校正曲線
GET /api/impact/merchants5 間試點商戶的發碼／核銷／到訪率與週走勢

成效數據為複賽示範數據（賽規允許非真實數據），僅到區域／商戶彙總粒度，不含任何個人資料。

3. 一次性到店碼 API

端點內容
POST /api/codes/issue請求體 {"poi_id": "wong_chi_kei"}；只對舊區／本地商戶點發碼，返回 EL-XXXX-XX 格式一次性碼與商戶禮遇
POST /api/codes/redeem請求體 {"code": "EL-XXXX-XX"}；返回 redeemed / already_redeemed / invalid，核銷一次即失效

可在成效儀表板的核銷演示機體驗完整「領碼 → 核銷 → 重複核銷被拒」閉環。
